# Календарь ивентов (вкладка в ClubPage, оба дизайна)

## Контекст findings
- Сущность одна: `ClubEvent` (`EventType`: `"Tournament"` / `"Campaign"`, `StartTime`/`EndTime`, `GameSystem`, `Status`: null/Completed/Archived). Связи кампания↔турнир нет — только пересечение дат.
- `GET /api/event/club/{clubId}` уже отдаёт все события клуба; ClubPage уже грузит их в state `events`. **Бэкенд и БД не трогаем** — чисто фронтенд.
- 17 игровых систем — в `src/constants.ts` (`ALL_GAME_SYSTEMS`); per-system цветов пока нет нигде.
- Шаблон сетки месяца: `src/components/BookingCalendar.tsx` (Пн-первый, ru-локаль) + legacy-копия.
- Конвенция дублирования: компоненты — в `src/components/` (grimdark, `--gd-*`) и `src/components/legacy/` (hex); чистую логику/константы делим, не дублируем; правки ClubPage — во все 4 блока (mobile+desktop × grimdark+legacy).

## Отображение (главное требование — пересечения и цвета систем)
- Месячная сетка, Пн-первый. Навигация ‹ Месяц Год › + «Сегодня».
- **Цвет = игровая система** (`GameSystem` → фиксированный цвет из новой карты `GAME_SYSTEM_COLORS`).
- **Кампания** в клетке дня → фоновая заливка полосой цвета системы (alpha ~0.3). **Несколько пересекающихся кампаний** → клетка делится на равные горизонтальные полосы (`linear-gradient` из N сегментов) — все видны одновременно.
- **Турнир** в клетке дня → цветная точка цвета системы под номером (до 3 точек, дальше «+N», `title`-подсказка). Турниры лежат внутри дат кампаний → точки поверх полос, формы не конфликтуют.
- Сегодня — рамка; выбранный день — подсветка; завершённые события — приглушены (opacity); архивные — отфильтрованы (как во вкладке «События»).
- **Легенда** под сеткой: чипы систем, встречающихся в событиях клуба; клик по чипу — вкл/выкл фильтр этой системы (скрывает её полосы/точки). Пустой `gameSystem` → нейтральный цвет, чип «Без системы»; неизвестный текст → детерминированный хэш в палитру.
- **Клик по дате → панель дня** под календарём: кампании, идущие в этот день (название, система, полный диапазон дат, ГМ) и турниры (время, название, система, участники/лимит, ГМ). Только просмотр; регистрация остаётся во вкладке «События».

## Новые файлы
1. `src/constants.ts` (правка): + `GAME_SYSTEM_COLORS: Record<string, string>` — кураторская палитра для всех 18 систем (различимая на тёмном и светлом фоне).
2. `src/utils/eventCalendar.ts` (новый, общий — НЕ дублируется):
   - `interface EventCalendarItem` (минимальный структурный подтип `ClubEventItem`: id, title, startTime, endTime, eventType, gameSystem?, status?, gameMasterName?, maxParticipants?, participants?);
   - `systemColor(system?)`, `withAlpha(hex, a)`;
   - `monthGrid(year, month): (Date|null)[][]` (Пн-первый);
   - `campaignsCoveringDay(events, date)` (дата-уровень, конец включительно), `tournamentsOnDay(events, date)`.
3. `src/components/EventCalendar.tsx` — grimdark-версия (inline-стили на `--gd-*`, по образцу BookingCalendar).
4. `src/components/legacy/EventCalendar.tsx` — зеркальная legacy-версия (hex: фон `#1a1a2e`/`#16213e`, акценты `#0f3460`/`#e94560`, текст `#eee`).

## Правки ClubPage (×2 файла, по 6 точек в каждом)
`src/pages/ClubPage.tsx` и `src/pages/legacy/ClubPage.tsx`:
1. Юнион `mobileTab` (~стр. 184 / legacy-аналог): + `'calendar'`.
2. Юнион `desktopTab` (~стр. 186): + `'calendar'`.
3. Mobile tab bar (~851, double-quoted): + `"calendar"` + метка «Календарь».
4. Desktop tab bar (~1380, single-quoted): + `['calendar', '🗓️ Календарь']`.
5. Mobile render block: `mobileTab === "calendar" && <EventCalendar events={events.filter(e => e.status !== 'Archived')} />`.
6. Desktop render block: то же с `desktopTab === 'calendar'` (legacy-файл импортирует `../components/legacy/EventCalendar`).
